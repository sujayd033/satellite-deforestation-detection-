# Assets

This directory contains static assets for the project.

## Contents

- `demo.gif` - Placeholder for demo GIF (not included in git)

## Adding Assets

To add a demo GIF:
1. Record a demo of the system
2. Save as `demo.gif`
3. Update README.md to display it

## Screenshots

To add screenshots:
1. Take screenshots of the system
2. Save as descriptive names (e.g., `prediction.png`, `heatmap.png`)
3. Update README.md to display them
