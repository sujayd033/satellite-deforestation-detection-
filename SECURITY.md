# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.0   | ✅        |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately to avoid putting users at risk.

**How to Report:**
- Email: sujaydharmavar@gmail.com
- Subject: [Security] Vulnerability Report

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if known)

**Response Time:**
We will acknowledge receipt within 48 hours and provide a response within 7 days.

## Security Best Practices

For Users:
- Keep dependencies updated
- Use virtual environments
- Review code before running in production
- Don't commit sensitive data (API keys, credentials)

For Contributors:
- Follow secure coding practices
- Validate all inputs
- Use parameterized queries
- Keep dependencies updated
- Review security advisories

## Security Features

- No external API keys required
- Local model inference (no data leaves your system)
- Input validation on file uploads
- Safe file handling practices

## Disclosure Policy

- Vulnerabilities will be fixed within a reasonable timeframe
- Security patches will be released as soon as possible
- Credit will be given to reporters (if desired)
- Coordinated disclosure will be practiced
