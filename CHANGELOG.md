# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Added
- Initial release of deforestation detection system
- CNN-based model with transfer learning support
- Data preprocessing with NDVI calculation
- Training pipeline with sample data generation
- Inference pipeline for single and batch predictions
- Visualization tools (heatmaps, comparisons, reports)
- CLI interface for easy usage
- GitHub Actions CI/CD pipeline
- Comprehensive documentation

## [1.0.0] - 2024-10-09

### Added
- Core deforestation detection system
- Model architectures (ResNet50, EfficientNetB0, VGG16, Simple CNN)
- Satellite image processing
- Vegetation analysis (NDVI, forest coverage)
- Change detection between time periods
- Batch processing capabilities
- Visualization and reporting
- Configuration management
- Professional documentation
- GitHub templates (issues, PRs)
- CI/CD pipeline
- Security policy
- Code of conduct
- Contributing guidelines
